OPTION A: Quick Select (NEW)
────────────────────────────
1. User taps "Spiritual + Nature" card
2. Categories auto-selected: Devotional + Eco Tourism
3. Counter shows "2 selected"
4. Discovery buttons appear
5. Continue button enabled

OPTION B: Manual Selection (EXISTING)
─────────────────────────────────────
1. User taps individual category tiles
2. Each tap toggles selection on/off
3. Counter updates dynamically
4. Discovery buttons appear when > 0 selected
5. Continue button enabled when > 0 selected

OPTION C: Hybrid (NEW + EXISTING)
─────────────────────────────────
1. User taps "Family Complete" → 4 categories selected
2. User manually deselects "Educational" → 3 remain
3. User adds "Corporate" → 4 total
4. Full flexibility!
