## 🎓 KEY LESSONS FOR YOUR TEAM

### **✅ What Worked Well:**

1. **Figma for Design, React for Code**
   - Use Figma as visual reference
   - Hand-craft production code
   - Don't use Figma exports directly

2. **Component Reusability**
   - One component for all cards
   - Data-driven approach
   - Props for customization

3. **Accessibility First**
   - Built in from day one
   - Semantic HTML
   - ARIA labels throughout

4. **Mobile-First Responsive**
   - Start with mobile
   - Enhance for larger screens
   - Test all breakpoints

5. **External Integrations**
   - Google/YouTube links work perfectly
   - Simple but effective

### **⚠️ Avoid These Mistakes:**

1. ❌ **Using Figma export code directly**
   - Always produces bad code
   - Not accessible
   - Not responsive
   - Not maintainable

2. ❌ **Absolute positioning**
   - Use Flexbox/Grid instead
   - Much more flexible
   - Responsive by default

3. ❌ **Hardcoded content**
   - Use data arrays
   - Props for customization
   - Easy to update

4. ❌ **Divs for buttons**
   - Use proper `<button>` elements
   - Essential for accessibility
   - Better semantics

5. ❌ **Fixed dimensions**
   - Use responsive units
   - Let content dictate size
   - Works on all screens
